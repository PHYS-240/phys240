API reference
=============

.. currentmodule:: phys240

The assertion replacements (``assert_equal``, ``assert_almost_equal``,
``assert_raises``, ...) are bound directly from a ``unittest.TestCase``
instance and are documented upstream in :mod:`unittest`; they are omitted
here.  Their signatures and messages are identical to the ``nose.tools``
names they replace.
